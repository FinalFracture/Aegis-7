## Bugs
### SYS-01 — Medium — Engine resource leaks at exit
Repro: `godot --headless --path godot --script <loader>` (or plain headless boot); observe exit.
```
WARNING: 150 ObjectDB instances were leaked at exit
ERROR: 58 RID allocations of type ...DummyMaterial were leaked at exit.
ERROR: 40 RID allocations of type ...DummyTexture were leaked at exit.
ERROR: 10 ...DummyShader / 4 ...DummyMesh / 4 RendererSceneCull::Instance leaked
WARNING: Leaked instance dependency: Bug - did not call instance_notify_deleted when freeing. (x4)
```
Likely code-created resources/RIDs (RenderingServer/procedural meshes) not freed on quit via get_tree().quit() mid-frame.

### SYS-02 — Low — Navmesh edge merge errors on boot
`WARNING: Navigation region synchronization had 8 edge error(s). More than 2 edges tried to occupy the same map rasterization space.` Repro: any boot. Risk: nav pathing gaps.

### SYS-03 — Low — Unbound-in-code input actions / hardcoded keys
interact, rfid_pulse, toggle_flashlight, toggle_view, toggle_lighting are defined in the input map but never queried via Input.is_action_* (grep). player_camera.gd:104-188 hardcodes KEY_TAB/C/1-5/F12/ESC/W/A/S/D/E/Q/SPACE/SHIFT, bypassing the remappable map. Verify these actions are handled elsewhere (e.g. _unhandled_input by event.is_action string from a variable) or remove/wire them.

### SYS-04 — Low (test infra) — Headless boot can't soak
Headless DisplayServer forces validate-and-quit (preface_playable_area.gd:417); _process_batch_render/automated_capture also quit on headless. Blocks CI stability soaks; suggest a `--qa-soak N` flag.
