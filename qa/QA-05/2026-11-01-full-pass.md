### SYS-03 confirmation
interact / rfid_pulse / toggle_flashlight / toggle_view / toggle_lighting are never read through InputMap (no is_action*, no event.is_action, no variable action names). They are handled in preface_playable_area.gd:2882 `_unhandled_input` by `match ke.physical_keycode`: E→_interact, F→_trigger_rfid_pulse, R→_toggle_flashlight, V/TAB→_toggle_view, N→_set_emergency_lighting. Hardcoded keys equal the map defaults, so they work but remapping does nothing. Also line 2279 polls KEY_F directly; player_camera.gd:99-188 hardcodes TAB/C/1-5/F12/ESC/WASD/E/Q/SPACE/SHIFT (E and TAB overlap with the gameplay bindings if both scripts are active). Only sprint/jump use is_action (2980-2981).

### SYS-07 — Medium (perf, needs T-02) — Main scene: 4010 meshes / 1018 unique materials
